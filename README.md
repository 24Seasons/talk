# 👋🏻 소개

## 24절기톡이란?

개발자, 디자이너 등 다양한 분야의 실무자들이 모여 [24절기](https://terms.naver.com/entry.naver?docId=1135069&cid=40942&categoryId=32286)에 맞춰 절기마다 자유 주제로 발표하는 커뮤니티입니다.

2022년 춘분부터 2024년 소한까지 **2년간 총 39회**를 진행했으며, 그중 38편을 영상으로 공개했습니다.

📺 발표 영상은 [유튜브 채널](https://www.youtube.com/@24seasons3/videos)에서 볼 수 있습니다.

## 24절기톡의 목적

무언가를 가장 잘 배우는 방법은 남에게 설명해 보는 것이라고 생각합니다. 각자 관심 있거나 배우고 싶은 주제를 골라 공부하고, 동료들 앞에서 발표하며 함께 성장하는 것을 목표로 합니다.

발표 주기를 약 15일 간격인 24절기에 맞춘 이유는 두 가지입니다.

- 부담이 크지 않은 간격
- 입춘·동지처럼 회차마다 이름이 붙어 모임을 기억하기 쉬움

## 어떤 방식으로 진행 되나요?

- **절기마다 1명 발표** — 주제는 자유입니다.
- **오프라인 진행** — 주로 회사 건물 안의 강의실을, 필요하면 외부 발표실을 빌렸습니다.
- **기록** — 발표 영상은 [유튜브 채널](https://www.youtube.com/@24seasons3)에 남겼습니다.

개발팀 안에서 시작한 모임이 디자인팀으로, 이어서 회사 전체로 넓어졌습니다. 그 결과 발표 주제도 개발에만 머물지 않았습니다.

# 🏁 시즌 1 마무리

개발팀 몇 명이 모여 시작한 자리가 디자이너 동료의 발표를 계기로 회사 전체로 넓어졌습니다. 30명 남짓한 직원 중 3분의 2 가까이가 참여했고, 나중에는 외부 발표자도 함께했습니다.

후반으로 갈수록 발표자와 청중이 줄고 회사 인원도 줄면서, **2024년 소한 발표를 마지막으로 시즌 1을 마무리**했습니다.

2년, 39번의 절기 동안 한 번도 발표를 거르지 않았다는 것. 화려하진 않았지만 멈추지 않고 이어갔다는 것 자체가 이 모임이 남긴 가장 큰 결과였습니다.
